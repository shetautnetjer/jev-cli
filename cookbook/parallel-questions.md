# Parallel questions

Questions over the same unchanged state can be submitted together when each is independently answerable.

Good:
- Choice: which route?
- Noul: does the request contain a prepared side effect?
- Score: how urgent is the request on a concrete rubric?

Bad:
- ask which route;
- then ask a second question whose candidate list depends on the first answer in the same request.

The second case needs another request after state or candidates are updated.
